EVIL NUN: SCHOOL'S OUT — OFFLINE BROWSER VERSION

HOW TO PLAY
1. Extract the entire ZIP folder somewhere on your computer.
2. Open the extracted folder.
3. Double-click Start_Game.bat.
4. Your browser will open the game. Keep the black PowerShell/launcher window open while playing.
5. Close the launcher window when you are done.

IMPORTANT
- Do not double-click index.html directly. Modern browsers restrict Unity's local file loading; the launcher provides a local-only address instead.
- This package serves the game from 127.0.0.1 on your own computer. It does not require an internet connection and does not expose the server to your local network.
- The first start can take a little while because the game loads a large local data file.
- Windows PowerShell is included with standard supported Windows installations. No Python, Node.js, or other server software is needed.
- Use a modern version of Chrome, Edge, or Firefox with WebAssembly enabled.

TROUBLESHOOTING
- If the browser does not open, copy the Local address shown in the launcher window into your browser.
- If another copy is already running, close it first and try again.
- Keep the extracted folder together; do not move or delete files inside Build or TemplateData.
